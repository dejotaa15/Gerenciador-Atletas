# Gerenciador de Atletas

Sistema desktop desenvolvido em Java com interface gráfica (Swing) para gerenciamento de atletas de diferentes modalidades esportivas.

## Funcionalidades

- Visualizar todos os atletas cadastrados
- Buscar atletas por nome
- Cadastrar novos atletas (Pista, Força e Natação)
- Ver estatísticas por categoria
- Ranking por número de medalhas

## Conceitos Aplicados

- Herança e Polimorfismo
- Coleções com ArrayList
- Programação funcional com Streams e Lambdas
- Interface gráfica com Java Swing
- Controle de versão com Git
